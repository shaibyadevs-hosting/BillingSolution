## 🎯 Overview

**Billing Solutions** is a comprehensive, offline-first billing and inventory management system designed for small businesses. It supports both offline (IndexedDB) and online (Supabase) modes, allowing businesses to operate seamlessly regardless of internet connectivity.

### Core Capabilities

- ✅ **Complete Offline Functionality** - Works without internet in IndexedDB mode
- ✅ **Dual Database Modes** - IndexedDB (offline) or Supabase (online sync)
- ✅ **GST Invoice Generation** - Full GST compliance with CGST/SGST/IGST
- ✅ **WhatsApp Integration** - Share invoices directly via WhatsApp
- ✅ **Multi-User Support** - Admin, Employee, and Customer roles
- ✅ **Real-time Analytics** - Dashboard with sales, inventory, and tax reports
- ✅ **Progressive Web App** - Installable, works offline, responsive design

## 🗄️ Database Modes

### IndexedDB Mode (Offline-First)

**When to Use:**
- Businesses without reliable internet
- Single-user or small teams
- Complete offline operation required
- License-based deployment

**Features:**
- ✅ Complete offline functionality
- ✅ Data stored locally in browser
- ✅ No internet required
- ✅ License protection
- ✅ HMAC session signatures
- ✅ Offline session management

**Limitations:**
- No cloud sync
- Data limited to single browser/device
- Manual backup required

### Supabase Mode (Online Sync)

**When to Use:**
- Multi-user environments
- Multi-device access required
- Cloud backup needed
- Real-time collaboration

**Features:**
- ✅ Cloud database (PostgreSQL)
- ✅ Multi-device sync
- ✅ Real-time updates
- ✅ Automatic backups
- ✅ Multi-user support
- ✅ Online authentication

**Limitations:**
- Internet connection required
- Supabase account needed
- No offline operation

### Mode Switching

**How it Works:**
- Admins can switch modes via admin management panel
- Mode change takes effect on next login
- Database is source of truth (not localStorage)
- Automatic mode detection on login
